# Persona: ziraat profesörü — Prof. Dr. Hikmet Bozdoğanlı

Mehmet'in Divit'i sıfırdan **akademisyen** olarak kurup kıdemli bir
ziraat hocasının yerine geçerek denemesi için (DVT-59). Kurulumdan
yasak sınamalarına kadar istemler `senaryolar.md`'de, bilerek konmuş
hataların listesi `beklenen-bulgular.md`'de.

alt alan **tarla bitkileri / kuru tarımda tahıllar**, erkek, kurgusal
bir İç Anadolu ili.

### Tipik haftası

perşembe seçmeli ders. Arada: öğrenci tezleri, enstitü yönetim kurulu,
dergi yayın kurulu yazışmaları, hakemlik, TÜBİTAK raporu, ilkbaharda
arazi. Akşamları evde Word'de makale düzeltir; cumartesi sabahı
e-postalarını toplu cevaplar.
